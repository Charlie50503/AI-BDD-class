# 永久筆記

這裡保存已淬鍊、可獨立理解與重用的原子筆記。**目前尚無逐篇確認完成的永久筆記；本檔為目錄說明。** 四篇既有主題筆記先保留在 [2-05 待淬鍊區](../../學習紀錄/2-05-Skill模組化概論/README.md)。

每張卡片說清楚一個完整想法，標題直接表達觀點，保留必要情境、來源單元與可追溯連結。從具體問題形成卡片，與相關卡片連結，再逐步建立 [索引](../索引/)。不為原子化切碎脈絡，也不由 AI 捏造你的心得；講師說明與你的理解應能分辨。

本機淬鍊完成與 Heptabase 同步是兩件事。同步時優先更新已有對應卡片，記錄卡片 ID 與讀回結果；課程白板保存來源脈絡，成熟卡片依當前 Space Instructions 決定主要領域。同一張卡片可在適用白板重用，避免內容副本。

方向依據與既有卡片核對見 [Heptabase 核對紀錄](../../學習紀錄/Heptabase核對紀錄.md)；目前狀態見 [總進度](../../README.md)。

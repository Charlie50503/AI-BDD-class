## 接著做什麼

1. 以 [練習/c2-7](練習/c2-7/) 為工作目錄開啟影片，手動建立 `.agents/skills/skill-form-rule/SKILL.md`。
2. 再建立 `.agents/skills/skill-form-rule/rules/RuleFile-格式規範.md`，先構思 Rule、Description、Good Example、Bad Example 的結構，跟影片逐步完成。此處保留給你練習，沒有預寫答案。
3. 過程記在 [2-07 跟練紀錄](學習紀錄/2-07-Rule格式把關/跟練紀錄.md)：影片停點、操作、Prompt、結果、疑問及你的理解。程式與 Skill 檔案留在練習目錄。
4. 跟練後再回顧，將完整想法淬鍊到 [筆記/永久筆記](筆記/永久筆記/README.md)，建立相關連結；需要導覽時再更新 [筆記/索引](筆記/索引/)。2-05 的四篇主題筆記也列在待淬鍊清單，毋須為開始 2-07 而先全部重寫。
5. 要求同步 Heptabase 時，先比對既有卡片，再按 Space Instructions 更新與放置，讀回確認後更新本表。
